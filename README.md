# Leitner · Μητρώο Θεμάτων Γνώσεων

Εφαρμογή PWA για iPhone με 1.988 ερωτήσεις, που δουλεύει χωρίς internet. Η πρόοδος μένει μόνο στη συσκευή.

## Αρχεία
- `engine.js`: η λογική των κουτιών, χωρίς οθόνες.
- `app.js`, `index.html`, `styles.css`: οι οθόνες.
- `sw.js`: η λειτουργία χωρίς internet.
- `questions.json`: οι ερωτήσεις, παραγόμενο αρχείο.
- `tools/build_questions.py`: ξαναχτίζει τις ερωτήσεις από τα PDF.
- `skills.json`, `skills/`: η ενότητα Δεξιότητες, παραγόμενα αρχεία.
- `tools/build_skills.py`: ξαναχτίζει τις Δεξιότητες από τα PDF της δοκιμασίας (χρειάζεται PyMuPDF και Pillow).
- `tests/engine.test.js`: δοκιμές με `node --test tests/engine.test.js`.

## Ενημέρωση
1. Αν άλλαξαν τα PDF, τρέξε το `tools/build_questions.py <φάκελος PDF> questions.json` (χρειάζεται PyMuPDF).
2. Αύξησε το `VERSION` στο `sw.js`, αλλιώς τα iPhone κρατούν την παλιά έκδοση.
3. Ανέβασε τα αρχεία στη φιλοξενία. Η εφαρμογή θα εμφανίσει «Υπάρχει νέα έκδοση».

Η πρόοδος συνδέεται με το περιεχόμενο κάθε ερώτησης, άρα διατηρείται αν αλλάξει μόνο η αρίθμηση. Μια ερώτηση με αλλαγμένο κείμενο μετρά ως νέα.
